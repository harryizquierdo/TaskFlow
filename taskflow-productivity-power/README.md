# TaskFlow Productivity Power

## Propósito

Este Power ayuda a organizar, priorizar y dividir tareas dentro de proyectos TaskFlow.

## Problema que resuelve

Cuando existen muchas tareas pendientes resulta difícil determinar:

- Qué hacer primero.
- Qué tareas dependen de otras.
- Qué tareas son demasiado grandes.
- Cómo dividir trabajo complejo en actividades pequeñas.

## Requisitos Previos

- Kiro IDE instalado.
- Acceso al panel Powers.

## Instalación

1. Abrir Kiro IDE.
2. Abrir Powers Panel.
3. Seleccionar Add Custom Power.
4. Seleccionar Import power from a folder.
5. Elegir la carpeta:

taskflow-productivity-power

6. Confirmar instalación.

## Configuración

Este Power no requiere configuración adicional.

## Skills Incluidos

### task-prioritizer

Responsable de:

- Analizar tareas.
- Detectar ambigüedades.
- Recomendar prioridades.
- Dividir tareas extensas.
- Generar planes de ejecución simples.

## Recursos Incluidos

Actualmente no requiere recursos adicionales.

## Configuración MCP

No utiliza MCP.

La integración MCP será demostrada de forma independiente en el punto 6.

## Variables de Entorno

No requiere variables de entorno.

## Ejemplo de Uso

Prompt:

Analiza estas tareas y genera una prioridad recomendada:

- Diseñar interfaz
- Crear persistencia
- Escribir pruebas
- Implementar filtros

## Resultado Esperado

El Skill debería:

- Priorizar tareas.
- Identificar dependencias.
- Sugerir subdivisiones cuando sea necesario.
- Proponer un orden de trabajo.

## Validación

Una vez instalado:

1. Abrir una conversación en Kiro.
2. Solicitar priorización de tareas.
3. Verificar que el Skill se active automáticamente.

## Seguridad

- No modifica archivos.
- No ejecuta comandos.
- No utiliza servicios externos.
- No almacena información.

## Limitaciones Conocidas

- No realiza estimaciones complejas.
- No utiliza inteligencia de negocio externa.
- No consulta APIs ni servidores.

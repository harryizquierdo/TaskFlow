# Guía de Priorización

## Prioridad Alta

Asignar prioridad alta cuando:

- La tarea bloquea otras actividades.
- Existe una fecha límite próxima.
- El impacto funcional es elevado.
- La tarea elimina riesgos importantes.

## Prioridad Media

Asignar prioridad media cuando:

- La tarea aporta valor, pero no desbloquea trabajo.
- Puede ejecutarse después de tareas críticas.
- No existe urgencia inmediata.

## Prioridad Baja

Asignar prioridad baja cuando:

- La tarea es opcional.
- La mejora es cosmética.
- No afecta funcionalidades principales.

## División de Tareas

Si una tarea contiene varias acciones independientes:

Ejemplo:

"Construir sistema de autenticación"

Dividir en:

- Diseñar modelo de usuario.
- Crear pantalla de login.
- Implementar validación.
- Implementar persistencia.
- Crear pruebas.

## Señales de Ambigüedad

Una tarea debe señalarse como ambigua cuando:

- No tiene resultado esperado.
- No tiene alcance definido.
- Combina múltiples objetivos.
- Utiliza expresiones vagas como:
  - mejorar
  - optimizar
  - revisar
  - arreglar varias cosas

## Recomendación General

Priorizar siempre:

1. Riesgos.
2. Dependencias.
3. Valor entregado.
4. Mejoras opcionales.
